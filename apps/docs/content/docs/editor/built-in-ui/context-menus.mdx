Right-clicking or typing `/` after whitespace opens SuperDoc's built-in menu. Keep those triggers, disable slash opening,
or open the menu from your application.

## Try the context menu

Expand the Editor, then select “Select this sentence, then right-click it to open the document menu.”

1. Right-click the selection with **Add action** selected, then choose **Send selection to workflow**.
2. Confirm that the line below the Editor reports the selected text.
3. Change **Menu** to **Default**, select the sentence, and right-click again. SuperDoc's actions remain, but the
   application action no longer appears.

Changing the menu configuration reloads the current DOCX because `ui.contextMenu` is a startup option. Document edits
remain; the selection and open menu reset.

## Open the menu from your application

Set `openOnSlash: false` when your application owns the keyboard shortcut. Right-click still opens the menu. A button,
shortcut, or other application control can call `superdoc.ui.contextMenu.open()` at the current selection or caret:

`open()` returns `{ ok: false, reason }` when the Editor is not ready, the document is read-only, or there is no usable
selection geometry. Call `superdoc.ui.contextMenu.close()` when your application needs to dismiss the menu; calling it
when the menu is already closed is safe.

`showWhen()` receives the document context captured when the menu opens. The example requires a right-click trigger and
an expanded selection, so the action does not appear after `/`, a programmatic `open()`, or a collapsed caret.

`onSelect()` runs after the menu closes. The example awaits `context.selectedTextSettled` because it needs the final
selection text. If an action must preserve the click's user activation for `navigator.clipboard`, `window.open`, or a
file picker, use `context.selectedText` synchronously instead of awaiting first.

## Choose how much of the menu to change

| Result                                        | Configuration                         |
| --------------------------------------------- | ------------------------------------- |
| Keep SuperDoc's actions and add yours         | `sections`                            |
| Show only configured application actions      | `sections` with `defaultItems: false` |
| Filter or reorder the final resolved sections | `menuProvider(context, sections)`     |
| Render the complete menu in your application  | `ui: { contextMenu: false }`          |

Use `showWhen()` on an item for ordinary context checks. Reserve `menuProvider()` for changes that need the complete
resolved section list.

Continue with [Application-owned context menus](/editor/custom-ui/context-menus) when your application should render the
surface, or [Structured content](/editor/built-in-ui/structured-content) to configure controls for tables, images, and
content controls.
