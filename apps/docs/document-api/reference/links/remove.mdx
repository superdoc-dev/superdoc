## Summary

Remove a hyperlink from the document.

- Operation ID: `links.remove`
- API member path: `editor.doc.links.remove(...)`
- Mutates document: `yes`
- Idempotency: `non-idempotent`
- Supports tracked mode: `no`
- Supports dry run: `no`
- Deterministic target resolution: `yes`

## Expected result

Returns a LinkMutationResult indicating success or a failure.
