## Summary

Get detailed information about a specific hyperlink.

- Operation ID: `links.get`
- API member path: `editor.doc.links.get(...)`
- Mutates document: `no`
- Idempotency: `idempotent`
- Supports tracked mode: `no`
- Supports dry run: `no`
- Deterministic target resolution: `yes`

## Expected result

Returns a LinkInfo object with the link's destination, tooltip, and display text.
