`useSuperDocDocument()` exposes `{ ready, mode }`. `ui.document.setMode('suggesting')` flips the editor into Suggest mode. `ui.document.export({ exportType: ['docx'] })` returns a downloadable DOCX. `ui.document.replaceFile(file)` swaps the open document — handy for round-trip testing.
